Welcome to the VFS Agent Demo

This multi-page website was created using the VFS Agent - a client-side AI agent that runs entirely in your browser with:

  • Virtual File System with IndexedDB persistence
  • WASM-powered tools (Python, SQLite, FFmpeg, Git)
  • ReAct-style agent loop with tool use
  • Live preview iframe for HTML files
  • ZIP import/export with drag-drop
  • Dark/light theme support
