Run Python with NumPy and Pandas directly in the browser:

Example: SQLite Database

Create and query databases entirely in-browser:

-- Initialize database CREATE TABLE users ( id INTEGER PRIMARY KEY, name TEXT NOT NULL, email TEXT UNIQUE, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ); -- Insert data INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com'), ('Bob', 'bob@example.com'); -- Query SELECT * FROM users WHERE created_at > datetime('now', '-1 day');
