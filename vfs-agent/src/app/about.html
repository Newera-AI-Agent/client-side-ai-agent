What is VFS Agent?

VFS Agent is a fully client-side AI agent that runs entirely in your browser. It combines a virtual file system with powerful WASM-based tools to give you a complete development environment without any server.

All computation happens locally - your code, files, and data never leave your machine.

Technology Stack

Frontend

  • Next.js 16 (App Router)
  • React 19
  • TypeScript (strict)
  • Tailwind CSS 4

Runtime

  • Pyodide (Python WASM)
  • sql.js (SQLite WASM)
  • FFmpeg.wasm
  • isomorphic-git

Storage

  • IndexedDB (idb)
  • localStorage (Zustand)
  • In-memory VFS

Editor

  • Monaco Editor
  • Syntax highlighting
  • TypeScript support

Privacy First

Everything runs in your browser:

  • No API keys required for local tools
  • Files stored in IndexedDB (your browser)
  • Code executes in WASM sandboxes
  • No telemetry or tracking
  • Works offline after initial load
